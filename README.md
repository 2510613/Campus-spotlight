# Campus Spotlight website

A responsive static website concept for Campus Spotlight.

## Files
- `index.html` — website content and structure
- `style.css` — colours, layout and responsive styling
- `script.js` — mobile navigation and demo enquiry form

## Publish with GitHub Pages
1. Create a **public** GitHub repository named `campus-spotlight`.
2. Upload `index.html`, `style.css`, `script.js`, and this README to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch `main` and folder `/(root)`, then save.
6. Wait for GitHub Pages to publish. Your URL will look like:
   `https://YOUR-USERNAME.github.io/campus-spotlight/`

## Important
This is a demonstration website. The contact form does not send or store submissions, and the booking buttons are enquiry prompts rather than a live booking/payment system. Connect a form backend and booking/payment provider before using it with real customers. Replace the example photos and proposed pricing with approved business content before launch.
